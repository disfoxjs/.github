Why Disfox?

Disfox is built to enhance the Discord.js experience by providing automation, structure, and practical tools for Discord application development.

Better Organization

As Discord applications grow, keeping commands, events, services, and business logic organized becomes increasingly important.

Disfox encourages a structured architecture where each part of the application has a clear responsibility, helping projects stay maintainable and scalable.

Less Boilerplate

Spend less time configuring your application and more time actually building it.

Disfox provides tools that automate repetitive parts of Discord.js development, including:

- Automatic command discovery from directories
- Conversion into Discord.js-compatible data
- Structure validation before registration
- Flexible extraction and registration options

BehaviorTables

BehaviorTables simplify permissions, restrictions, and execution rules through a centralized and declarative system.

Keep validation logic out of your commands and define how your application should behave in a cleaner way.

JavaScript & TypeScript

Disfox supports both JavaScript and TypeScript.

TypeScript developers get strong typing, autocompletion, and improved tooling, while JavaScript developers can use Disfox without changing their existing workflow.

Designed for Real Projects

Disfox was built to solve problems commonly found in medium and large Discord applications.

File management, command registration, validation, permissions, and application structure shouldn't become a mess as your project grows.

Performance Matters

Higher-level abstractions shouldn't mean unnecessary overhead.

Disfox is designed to provide automation and developer-friendly APIs while keeping applications fast and efficient.

Open Source Community

Disfox is completely open source and evolves through community feedback, contributions, bug reports, and feature suggestions.
